# BLU 8.0.8

Released 2026-09-20.

- Added a minimap button via `RGXMinimap:Create` with BLU branding: the BLU icon and cyan title, tooltip lines for status, Left-Click (open options), Left-Drag (reposition), and Ctrl+Right-Click (hide).
- Added a **Show minimap icon** toggle to the General options pane, bound to the `minimapIconEnabled` profile key and applying live.
- Added `/blu icon on|off` to show or hide the minimap button.
- Visibility and drag angle persist in the active profile (`minimapIconEnabled`, `minimapAngle`); a proxy storage keeps the button bound to the current profile across profile switches.
- TOC interface list became `120100,16001`: added the beta interface `16001` but incorrectly removed interface `120007`, which is the validated WoW Forever Beta `1.60.1.69893` interface (restored in v8.0.9).

Requires RGX-Framework v2.7.5 or later.
