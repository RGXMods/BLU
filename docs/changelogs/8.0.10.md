# BLU 8.0.10

## Fixed

- Corrected the TOC interface list to `120100,16001`. Retail live (`12.1.0`) is `120100`; WoW Forever (classic beta, build `1.60.1.x`) derives as `1*10000 + 60*100 + 1 = 16001`. The `120007` value retained in v8.0.9 is the Retail `12.0.7` interface, not a Forever value; it is removed again. The verified derivation table lives in `AGENTS.md` (`Keeping Interface Versions Current`).
- Synchronized the `core/core.lua` version fallback (was `v8.0.7`) with the TOC version.

## Added

- `AGENTS.md` now carries the `Building With RGX-Framework` and `Keeping Interface Versions Current` directives.

## Notes

- No in-game behavior changed; metadata, documentation, and the version fallback only.
