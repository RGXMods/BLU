# v8.0.2 — 2026-07-03

## Fixed

- **`LUA_WARNING: Error loading core/sounds/user_sounds_generated.lua`** — this file was gitignored and its generator script was never tracked either, so `BLU.xml` referenced a file that literally never shipped in any package. Every player hit this on login. Now ships a safe empty-manifest default so the file always exists.
- **Slider visual inconsistency** — the Channel Volume slider (General tab) used a bare Blizzard `OptionsSliderTemplate` with its own ad-hoc restore path, structurally different from every per-event tab's custom slider. Migrated to `RGX-Framework`'s `UI:CreateSlider` — the framework's proven, db-bound implementation.
- **Nested-dropdown Play/Stop label lag** — the Play button did not flip to "Stop" on the first click even though playback started correctly (a second click correctly stopped it). The label now reads from the single authoritative `IsPreviewPlaying` check used everywhere else in the file, instead of `PreviewSound`'s return tuple.

## Changed

- External-sound discovery migrated to the shared `RGXSharedMedia` framework module. `core/sounds/sharedmedia.lua` is now a ~217-line bridge (was ~830) that imports scan results into `BLU.SoundRegistry` and re-exports the public bridge API, with dedup-on-import so the shared registry can scan every addon folder — including BLU's own — without duplicating entries.

## Upgrade Notes

No breaking changes. Requires RGX-Framework v2.2.1 or later (for `UI:CreateSlider` and `RGXSharedMedia`, both already required by earlier BLU releases).
