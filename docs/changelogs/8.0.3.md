## v8.0.3 - 2026-07-03

**New combat trigger: Lust / Heroism Sound.**

The Combat tab's generic "proc" trigger fires on any aura gain, with no way to react specifically to a bloodlust-class buff. This adds a dedicated `lust_sound` trigger, configurable independently (its own sound + volume selection) from Combat's existing sound triggers.

Fires when any of these land on you:

- Bloodlust (Shaman)
- Heroism (Shaman)
- Time Warp (Mage)
- Ancient Hysteria (Hunter exotic pet ability)
- Primal Rage (Evoker)

Matched by spell ID against the `UNIT_AURA` event's `updateInfo.addedAuras` payload (the same incremental-update contract RGX-Framework's `modules/auras/auras.lua` already relies on) — locale-independent, unlike name matching.
