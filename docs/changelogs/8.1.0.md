# BLU v8.1.0

## New
- **Collectibles triggers**: mount, pet, toy, and transmog appearance acquisitions now play their selected category sound. Both transmog source events (standard and cosmetic) share the transmog cooldown. The module honors `BLU.db.modules.collectibles`, and each category has a default sound so it works out of the box. Per-type sound selection in the Collectibles tab is still planned.

## Cleanup
- Removed the unused combat prototype panel and its mock trigger-page fixtures (~430 lines), the unused `QuestPanel.lua` module, unused tab/helper functions, and duplicate module-toggle maps in the loader and initialization manager. No behavior changes.
